# Credits: Jonkler: The One and Only

All game code and every sprite (Jonkler, mimes, Fun Police, pigeons, Chief Killjoy, the pillar,
the city skyline) were made from scratch for this jam. Sprites are drawn in code from rectangles,
so the game has no image files.
